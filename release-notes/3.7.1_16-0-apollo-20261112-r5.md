Unofficial **YARP** (`twrp-16.0`, LVGL gui2) for **Xiaomi Mi 10T Pro / Mi 10T / Redmi K30S Ultra (apollo, apollon)**.

### New in r5
- **The two write-guard switches are now off by default**: "Protect recovery partition during zip install" and "Protect boot partition (kernel) during zip install" (Settings → General). Turn them on if you want a ROM zip prevented from replacing recovery or your kernel. Your saved setting is kept once you change it.
- Built by [GitHub Actions](https://github.com/ElDavoo/twrp_device_xiaomi_apollo/actions/runs/43938669701) from this repo. Vendor blobs come from the LineageOS apollon OTA, as in r4.

Everything else is the same as r4: erofs vendor/odm support, `/data` decryption with a PIN, status bar on the right.

**Not yet tested on the phone.** Only the default of the two switches changed since r4, which was tested.

### Install
```
fastboot boot yarp-3.7.1_16-0-apollo-20261112-r5.img      # try it first
fastboot flash recovery yarp-3.7.1_16-0-apollo-20261112-r5.img
```
