Unofficial **YARP** (`twrp-16.0`, LVGL gui2) for **Xiaomi Mi 10T Pro / Mi 10T / Redmi K30S Ultra (apollo, apollon)**.

### New in r4
- **Built by GitHub Actions** ([workflow](https://github.com/ElDavoo/twrp_device_xiaomi_apollo/blob/main/.github/workflows/build.yml), run [#6](https://github.com/ElDavoo/twrp_device_xiaomi_apollo/actions/runs/43672391796)). Anyone can rebuild it from this repo. The vendor keymaster/gatekeeper/qseecom blobs are now extracted from the public LineageOS apollon OTA (`lineage-24.0-20261114`) instead of being pulled from a phone. They match the blobs used in r3, plus `libspcom.so`, which the extraction list was missing.
- The write guard's install log now names the partition it checked (`Write guard: /dev/block/sde50 unchanged`). Before, it always said "recovery", even for boot.

Everything else is the same as r3:
- Zips can't overwrite the **recovery** or **boot** (kernel) partitions. See Settings → General, both are on by default.
- erofs vendor and odm are supported.
- `/data` decryption works with a PIN.
- The status bar is on the right.

**Tested on the phone** (M2007J3SG, LineageOS 24.0) with `fastboot boot`:
- keymaster, gatekeeper and qseecomd start with the OTA-extracted blobs.
- `/data` metadata decryption works, and user 0 decrypts with a PIN.
- The recovery and boot write guards block edify and `dd` writes (`Operation not permitted`), and restore boot after a zip clears the read-only flag. Both partition hashes were unchanged.

### Install
```
fastboot boot yarp-3.7.1_16-0-apollo-20261112-r4.img      # try it first
fastboot flash recovery yarp-3.7.1_16-0-apollo-20261112-r4.img
```
